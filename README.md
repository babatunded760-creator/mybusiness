# Your Business website starter

A responsive multi-page static site inspired by the supplied reference: warm cream backgrounds, forest green accents, serif headlines, subtle gold details and a professional layout.

## Files
- `index.html` — homepage
- `about.html` — about and values
- `services.html` — service descriptions
- `contact.html` — enquiry form
- `styles.css` — shared responsive design
- `script.js` — mobile navigation and form behaviour
- `favicon.svg` — placeholder logo mark

## Before publishing
Replace `Your Business`, `[CITY, COUNTRY]`, all sample service copy, `hello@example.com`, and `[Add business phone]` with the real client's information. Only add verified contact details and claims.

The contact form validates the fields and opens the visitor's email app with a prepared message. It does not store or send messages on a server. For direct form submissions, connect and test a real form provider or backend.

## Run and deploy
This is a static site and needs no npm install or build step. Open `index.html` in a browser or use VS Code Live Server. Deploy the folder contents to a static host such as Netlify, GitHub Pages or Vercel. No environment variables are required for this placeholder version.
